A mesma regra, escrita duas vezes

Controlar prazos é boa parte do meu trabalho. As regras de contagem dos códigos de processo civil são precisas o bastante para virar algoritmos. Compare a regra brasileira, que conta só dias úteis, com a portuguesa, que corre de forma contínua e se suspende nas férias judiciais.

Na lei

Na contagem de prazo em dias, estabelecido por lei ou pelo juiz, computar-se-ão somente os dias úteis.Original: “Na contagem de prazo em dias, estabelecido por lei ou pelo juiz, computar-se-ão somente os dias úteis.”CPC, art. 219
Salvo disposição em contrário, os prazos serão contados excluindo o dia do começo e incluindo o dia do vencimento.Original: “Salvo disposição em contrário, os prazos serão contados excluindo o dia do começo e incluindo o dia do vencimento.”CPC, art. 224
O prazo processual, estabelecido por lei ou fixado por despacho do juiz, é contínuo, suspendendo-se, no entanto, durante as férias judiciais, salvo se a sua duração for igual ou superior a seis meses ou se tratar de atos a praticar em processos que a lei considere urgentes.Original: “O prazo processual, estabelecido por lei ou fixado por despacho do juiz, é contínuo, suspendendo-se, no entanto, durante as férias judiciais [...]”CPC português, art. 138.º, n.º 1
Quando o prazo para a prática do ato processual terminar em dia em que os tribunais estiverem encerrados, transfere-se o seu termo para o 1.º dia útil seguinte.Original: “Quando o prazo para a prática do ato processual terminar em dia em que os tribunais estiverem encerrados, transfere-se o seu termo para o 1.º dia útil seguinte.”CPC português, art. 138.º, n.º 2
from datetime import date, timedelta

def vencimento(intimacao: date, dias: int) -> date:
    """Contagem de prazo do CPC, arts. 219 e 224."""
    atual, contados = intimacao, 0
    while contados < dias:
        # art. 224: exclui o dia do começo
        atual += timedelta(days=1)
        # art. 219: só contam os dias úteis
        if atual.weekday() < 5:
            contados += 1
    # art. 224: inclui o dia do vencimento
    return atual
from datetime import date, timedelta

def due_date(served_on: date, days: int) -> date:
    """Brazilian CPC, arts. 219 and 224."""
    current, counted = served_on, 0
    while counted < days:
        # art. 224: the starting day is excluded
        current += timedelta(days=1)
        # art. 219: only business days count
        if current.weekday() < 5:
            counted += 1
    # art. 224: the final day is included
    return current
from datetime import date, timedelta

def termo(notificacao: date, dias: int) -> date:
    """CPC português, art. 138.º"""
    atual, contados = notificacao, 0
    while contados < dias:
        # CC, art. 279.º, b): exclui o dia inicial
        atual += timedelta(days=1)
        # n.º 1: contínuo, suspenso nas férias
        if not ferias_judiciais(atual):
            contados += 1
    # n.º 2: tribunal fechado leva o termo
    # ao 1.º dia útil seguinte
    while atual.weekday() >= 5:
        atual += timedelta(days=1)
    return atual
from datetime import date, timedelta

def end_of_term(notified_on: date, days: int) -> date:
    """Portuguese CPC, art. 138."""
    current, counted = notified_on, 0
    while counted < days:
        # Civil Code, art. 279(b): first day excluded
        current += timedelta(days=1)
        # art. 138(1): continuous, paused in court holidays
        if not court_holidays(current):
            counted += 1
    # art. 138(2): courts closed, move to next business day
    while current.weekday() >= 5:
        current += timedelta(days=1)
    return current
